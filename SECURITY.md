# Security

shardfit is a CLI that reads and writes files you point it at. It does not
run as a service, store secrets, or accept untrusted network input beyond
fetching the timing store URL you configure.

## Reporting

If you find a vulnerability, please report it privately so it can be fixed
before public disclosure:

1. Use GitHub's **private vulnerability reporting** on the repo (Security →
   Report a vulnerability), or
2. Message a maintainer directly.

Please include the affected version and a minimal reproduction. Do not open a
public issue for security findings. Fixes are published as patch releases
with credit to the reporter.
